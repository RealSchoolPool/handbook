## Что изменилось

В [плане недели](WEEK-03.md) среда рассчитывалась на три часа и несла две темы: фильтр и git.
В 105 минут помещается одна.

**Режется git.** Уезжает на четверг целиком — и это правильный порядок, а не вынужденный:
сначала появляется то, что стоит сохранить, потом учимся сохранять. Коммитить пустой файл —
ритуал, коммитить свою работающую программу — нет.

**Не режется фильтр.** Без него у команд нет скелета продукта, а в пятницу на сервер нечего
класть.

> **Цель дня:** к 13:00 у каждой команды есть программа, которая печатает из их собственных
> данных только нужное.

## Тайминг

### 11:15–11:20 · Где мы (5 мин)

Цель одним предложением: **«сегодня ваша программа начнёт работать на ваших настоящих данных»**.

### 11:20–11:45 · Три конструкции (25 мин)

Ровно три, и ни одной сверх:

```text
  список   несколько значений в одной переменной
  for      сделать одно и то же с каждым
  if       сделать не для всех, а для подходящих
```

Пример на доске разбирать **на их данных**, а не на числах от 1 до 10. Берётся строка
из чьего-нибудь домашнего задания — находка, задание, кабинет — и на ней показывается цикл.

**Не упоминать:** словари, функции, методы списков, срезы. Каждое лишнее понятие здесь
стоит десяти минут позже.

### 11:45–12:35 · `task03` и `task04` (50 мин)

Ядро дня. Задания из [lessons/](../lessons/README.md), проверяет `check.py`, а не ты.

- `task03` — список → печать;
- `task04` — список → фильтр → печать.

Кто прошёл — **не сидит без дела**: переписывает `task04` под свои данные из ДЗ №3.

Сказать вслух до начала: **попытки не считаются против них**. Это первое, о чём спросят,
и если не сказать — половина будет бояться нажать «проверить».

Твоя роль сегодня смещается: не «проверять», а подходить к тем, у кого пятая попытка подряд.
`check.py` объясняет расхождения сам.

## Разнобой в данных — главный материал дня

Данные собирали разные люди. Почти наверняка окажется, что дата у одного `15.09`, у другого
`15 сентября`, у третьего её нет вообще, а у четвёртого есть колонка, которой нет ни у кого.

**Не чинить это за них.** Правило, которое стоит произнести буквально:

> Программа не может прочитать то, о чём люди не договорились.

Пусть команда сведёт формат словами — на бумаге, до кода. Это первый раз, когда они столкнутся
с тем, что формат данных есть договор между людьми, а не мелочь. Пять минут спора здесь
экономят неделю на шестой.

## Если пойдёт не так

| Ситуация | Что делать |
|---|---|
| Половина не прошла `task03` | Не идти в `task04`. Десять человек с работающим `for` лучше трёх с фильтром. Фильтр переносится на четверг, git — на пятницу |
| Данных из ДЗ №3 не принесли | Работают на списке из задания. Свои данные подставят в четверг, когда будут репозитории. Урок не останавливается |
| Прошли всё за 40 минут | Второй фильтр — два условия сразу. Дальше: чтение данных из файла |
| Не успеваем к 13:00 | Режется блок 12:35–12:55. `task03` и `task04` не режутся |
| Данные у команды несводимы | Отлично. Это и есть тема разговора: договориться о полях сейчас, на бумаге, а переписать строки — дома |
| Ники так и не собраны | Пять минут в конце, с телефонов, под твоим присмотром. Завтра без них не будет репозиториев |
